## GoldMetal Undead Survivor course assets

The base asset pack included with this project was created for GoldMetal's Vampire Survivors-like Unity development course. Its English notice states that the assets may be used for personal study, homework, and commercial projects, subject to the Unity Asset Store EULA.

- Course: https://www.youtube.com/playlist?list=PLO-mt5Iu5TeZF8xMHqtT_DhAPKmjF6i3x
- Creator: https://www.youtube.com/@goldmetal
- Included local notice: `Assets/Undead Survivor/ReadMe En.pdf`

The pack contains base enemy, item, tile, UI, audio, animation, and font resources. Project-specific gameplay logic, balancing, generated character sprites, interface changes, and documentation were produced for this repository.

## Background music

The public repository uses `Level 1` from the Retro Game Music Pack by Juhani Junkala. The embedded audio metadata identifies it as loop-ready and free to use anywhere.

The commercial track used in an earlier course presentation build is intentionally excluded from this repository and is not redistributed.
